## 0.1.2

Initial public release.

- Batch conversion from EMD 3.0 to EMX 3.7 with recursive folder support,
  collision detection, no-clobber output, dry runs, and JSON reports.
- Support for geometry, editable text, mapped paths, analytic/STL models,
  and flat bitmap projects.
- Independent binary and coordinate verification before publishing output.
- Native Group file framing, STL vertex/normal ordering, and Bezier
  anchor/control-handle ordering.
- Short uvx commands through PyPI, an installable Python package, and conversion
  issue reporting.
